# Student Registration System

## Project Description

The **Student Registration System** is a simple web-based application developed using **HTML5**, **CSS3**, **Git**, and **GitHub**. The project was created as part of **Assignment 1 – Version Control Using Git and GitHub** to demonstrate the complete Git workflow, including repository initialization, version control, branch management, merging, merge conflict resolution, and GitHub integration.

---

## Features

- Student registration form
- Student login form
- Responsive user interface
- Clean HTML and CSS structure
- Git version control
- Feature branch management
- Merge conflict resolution
- GitHub repository integration
