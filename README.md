# Student Registration System

A simple web-based student registration system created using HTML and CSS.

## Project Files

- `index.html` – Contains the student registration form.
- `style.css` – Contains the visual styling for the application.
- `README.md` – Contains information about the project.

## Features

- Student name input
- Email address input
- Course selection
- Student registration button

## Technologies Used

- HTML5
- CSS3
- Git
